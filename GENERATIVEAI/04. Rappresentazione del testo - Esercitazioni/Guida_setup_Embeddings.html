Setup dell'ambiente — Embeddings

Prepariamo l'ambiente Python necessario per lavorare con il notebook.

1. Crea la cartella del progetto

Crea una cartella per il progetto e inserisci al suo interno:

  • Embeddings.ipynb
  • requirements.txt
Tutti i comandi successivi devono essere eseguiti dal terminale aperto nella cartella del progetto.
2. Crea il virtual environment

Il virtual environment crea un ambiente Python separato per questo progetto.

Windows

py -m venv venv-embeddings

macOS / Linux

python3 -m venv venv-embeddings
3. Attiva il virtual environment

Windows — PowerShell

venv-embeddings\Scripts\Activate.ps1

Windows — CMD

venv-embeddings\Scripts\activate.bat

macOS / Linux

source venv-embeddings/bin/activate
Se l'attivazione è andata a buon fine, nel terminale comparirà (venv-embeddings).
4. Installa i requisiti

Il file requirements.txt contiene tutte le librerie necessarie.

Con il virtual environment attivo, esegui:

python -m pip install --upgrade pip

Poi installa tutte le dipendenze:

python -m pip install -r requirements.txt
Questo è l'ultimo passaggio del setup.
Una volta terminata l'installazione, l'ambiente Python è pronto per proseguire con il notebook.
5. In sintesi
1
Crea il virtual environment.
2
Attiva il virtual environment.
3
Installa le librerie con requirements.txt.
Ora possiamo iniziare con Embeddings.ipynb.
